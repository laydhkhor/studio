# **App Name**: DocAssist

## Core Features:

- Appointment Booking: Allow patients to book appointments (chat, video, clinic visit) with available slots. Integration with Google Meet for video consultations.
- Prescription Management: Enable doctors to create and manage prescriptions, including medicine name, dosage, days, when to take, and remarks, storing prescription details in Firestore.
- Medicine Reminder Notifications: Send medicine reminder notifications to patients 10 minutes before the scheduled time using Realtime Database.
- Doctor Review System: Allow patients to review and rate the doctor, with testimonials managed via Sanity CMS.
- Admin Dashboard: Provide a secure admin dashboard for the doctor to manage patients, bookings, prescriptions, and settings.
- Content Management: Utilize Sanity CMS for managing SEO content, blog posts, testimonials, FAQs, pricing, clinic information, and landing content.
- Automated SEO Optimization Tool: Automatically generate SEO-optimized content, meta descriptions, and structured schema based on the content managed in Sanity CMS, enhancing discoverability for keywords like 'Doctor in Mahishadal' and 'West Bengal healthcare consultation'. This tool analyzes the data to improve SEO.

## Style Guidelines:

- Primary color: A calm blue (#3498db) evoking trust and professionalism, rooted in the tradition of the healthcare industry.
- Background color: Very light blue (#e7f5fd), visibly in the same blue hue family as the primary color, but highly desaturated, supporting the clean and premium design aesthetic.
- Accent color: A complementary green (#2ecc71), placed approximately 30 degrees 'left' of the primary on the color wheel, indicating health and vitality.
- Headings font: 'Montserrat', a sans-serif font for clear and modern headings. Note: currently only Google Fonts are supported.
- Paragraphs font: 'Open Sans', a sans-serif font to ensure easy readability for body text. Note: currently only Google Fonts are supported.
- Subtitles/UI font: 'Poppins', a geometric sans-serif font for a contemporary feel in UI elements. Note: currently only Google Fonts are supported.
- Use consistent and recognizable medical icons throughout the application. Icons should align with the premium theme.
- Ensure clear card separation using proper shadows and consistent spacing. Maintain a fully responsive design with no overflow scrolling.
- Implement soft, subtle animations for a premium user experience. Animations should not be excessive.
